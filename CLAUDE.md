- Avoid local-minimum type solutions. If you're stuck, ask for help. 
- Readability matters more than optimality. Prefer simple, explicit code, even if it's slightly less efficient.
- Keep the call chain traceable with Ctrl+click (Go to Definition). Avoid indirection that hides where a function is called from: heavy DI containers, dynamic dispatch, string-based lookups, or deep generic abstractions.
- Files may import and call each other directly. What matters is that you can follow what a thread of execution is doing by reading the code
- When suggesting architectural changes, weigh how easy it is to trace a thread through the code above performance or cleverness. Name the tradeoff if a change makes tracing harder.

## Project layout                                                                                                                                                                                                                                                                                                 
  - `main.py`: entry point. pygame loop; calls `core/root.py` `Core.run()` each frame.                                                                                                                                                                                                                              
  - `core/`: scene flow. `root` (top-level state), `main_scene`, `cockpit`, `pause_menu`, `screens` (menus and lobby), `session` (multiplayer match state), `client`, `tactical_map_state`, `tutorial`.                                                                                                             
  - `objects/`: game entities. `ship`, `drone`, `missile`, `bullet`, `asteroid`, `decoy`, `false_contact`, `mining_vessel`, `explosion`, `base`.                                                                                                                                                                    
  - `instruments/`: player equipment. `radar_system`, `deep_field_scan`, `close_range_scan`, `laser_assessor`, `material_assessor`, `mining_laser`, `blink_drive`, `range_bands`, plus the `instrument` base class.                                                                                                 
  - `simulation/`: world state and rules. `world`, `grid`, `contacts`, `snapshot`, `settings`.                                                                                                                                                                                                                      
  - `netcode/`: multiplayer. `server`, `net_client`, `network_layer`, `callsign`.                                                                                                                                                                                                                                   
  - `ai/ai.py`: AI-controlled ships.                                                                                                                                                                                                                                                                                
  - `asset_handlers/`: drawing, audio, and fonts. `draw_game`, `draw_ui`, `buttons`, `crt`, `audio_manager`, `fonts`, `grime`, `readouts`.                                                                                                                                                                          
  - `config/`: `constants`, `theme`, `ui_constants`, `manual`, `precomputed_angles`.                                                                                                                                                                                                                                
  - `utility/`: `geometry`, `input`, `paths`, `profanity`, `text_input`, `timer`.                                                                                                                                                                                                                                   
  - `tests/`: pytest tests.                                                                                                                                                                                                                                                                                         
  - `assets/`: fonts, PNG images, sounds.                                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                    
  Skip `.venv/`, `dist/`, `build/`, `__pycache__/`, `.idea/`, and `.git/` when searching.
